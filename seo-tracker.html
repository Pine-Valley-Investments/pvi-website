SEO Dashboard Setup

Connect your Google Search Console property to track keyword rankings, clicks, impressions, and opportunities — all free, no third-party subscriptions needed.

1

Enable Search Console API

Go to Google Cloud Console, create or select a project, and enable the Google Search Console API.

2

Create OAuth 2.0 Credentials

In APIs & Services → Credentials, click Create Credentials → OAuth client ID. Select Web application. Under Authorized JavaScript origins, add both:
https://pvi-website.vercel.app and https://modica21-code.github.io
For local testing also add http://localhost.

3

Add OAuth Consent Screen

Under OAuth consent screen, set app name to PVI SEO Tracker, add mmodica@pinevalleyinvestments.com as a test user, and add the scope https://www.googleapis.com/auth/webmasters.readonly.

4

Paste Your Client ID Below

Copy the Client ID from the credential you just created. It looks like 123456789-abc.apps.googleusercontent.com.

This page only requests read-only access to your Search Console data. No data is sent to any external server — everything runs directly in your browser. Once set up, save the file to the PVI repo so both Mike M. and Mike C. can use it.
